편리한 기능

한글 문서 안의 글자도 찾습니다. 쪽 번호 표시, 전체 화면.

바로 인쇄

같은 Wi-Fi의 프린터로 바로 인쇄하거나 PDF로 저장합니다.

저장은 원할 때만

[저장]을 누를 때만 '다운로드' 폴더에 저장합니다. 받은 문서 자동 저장은 기본 꺼짐.

원본 글꼴

사용 권한이 있는 글꼴 파일을 넣으면 그 글꼴로 표시합니다.

설치·테스트 참여

지금은 구글 플레이 비공개 테스트 중입니다. 참여 방법은 테스트 안내를 보세요.

  1. 테스트 참여 신청(이메일 회신) 후 안내에 따라 테스터 되기를 누릅니다.
  2. 플레이 스토어에서 다봄뷰어를 설치합니다.
  3. 메신저·메일에서 첨부 파일을 누르고 다봄뷰어를 고르면 바로 열립니다. '항상'을 누르면 다음부터 묻지 않습니다.

개인정보 보호

다봄뷰어는 개인정보를 수집하지 않습니다. 광고·회원가입·분석 도구가 없고, 문서는 휴대폰 안에서만 처리합니다. 자세한 내용은 개인정보처리방침을 보세요.
